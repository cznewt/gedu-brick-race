# Compact mecanum car

A users' model by Aleš Komárek (2026-10-31). Four small green Geekservo 360 servos stand in a
tight frame of lime and yellow beams, outputs outward; the black 60 mm mecanum wheels sit
straight on the servos; the Wukong board stands upright on the frame with the micro:bit on top.
It drives with the Brick Race racer's driver (the *Elecfreak Wukong Mecanum Car* firmware, no
gears, so DIRECTION stays 1).

Studio file and parts list come with the next release. The board's mount (a grey 5-beam screwed
to the Wukong's edge) is drawn without a pin, as built.
